2. Purpose and scope

The browser extension adds a KLIPY-powered GIF picker to Twitch exclusively on the mister_rahman channel. It searches for GIF content, sends a GIF request selected by the user through regular Twitch chat, and locally renders confirmed GIF requests in chat. This functionality is disabled on all other Twitch channels.

3. Data processed and data flows

Data Processing and purpose Recipient
Current Twitch address Checked locally to ensure that the extension only activates on the mister_rahman channel. No transmission by the extension.
Twitch chat text and usernames Processed locally to recognize GIF requests, confirmations from the designated bot, and the release signal. The extension does not transmit chat text or usernames to the developer. A confirmed KLIPY slug is sent to KLIPY for resolution.
Current chat draft Temporarily read and restored locally when a GIF request is sent so existing text is not lost. No transmission to the developer or KLIPY. Twitch only receives content the user chooses to send through Twitch.
GIF search terms Required to provide matching search results. KLIPY.
KLIPY slugs Sent to KLIPY to resolve a GIF. When the user selects a GIF, the extension posts !rgif <slug> to Twitch chat following the user's explicit action. KLIPY, or Twitch and participants in the relevant public chat.
GIF media requests Previews and confirmed GIFs are loaded directly from approved KLIPY media servers. This necessarily exposes connection data such as the IP address, browser information, and request time. KLIPY.

Where the General Data Protection Regulation applies, processing is based on the legitimate interest in providing the expressly offered GIF feature securely and reliably (Article 6(1)(f) GDPR). 5. Storage and retention

The extension currently uses no persistent extension storage. Search state, the chat draft, and the request lock are processed briefly in the memory of the open Twitch tab and are discarded no later than when the page is closed or reloaded. The browser may cache loaded media according to its own cache settings.

Chat messages posted to Twitch and requests processed by KLIPY are subject to those providers' respective retention periods. The developer operates no backend server and receives no copy of this data.
