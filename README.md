# Mister_Rahman FREE GIFs privacy policy

Static bilingual privacy policy for the Mister_Rahman FREE GIFs browser extension.

## GitHub Pages configuration

The page is published from the repository root. In the repository, open
**Settings > Pages** and configure **Deploy from a branch** with the `main`
branch and the `/ (root)` folder.

The public URL is:

`https://rahman-machaka.github.io/twitch-free-gifs-privacy/`

Add this URL to the Chrome Web Store's privacy policy field after GitHub reports
a successful deployment.

The page intentionally contains no JavaScript, analytics, external fonts, or remote page assets.
